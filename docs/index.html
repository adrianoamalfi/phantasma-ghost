Ghost 6 theme · free · MIT

The photograph is the interface.

Phantasma is a theme for photographers: a light table and a contact sheet. A neutral grey ground, a safelight-red accent for what is selected, numbered frames, justified rows, series, a lightbox, and a fixed left rail.

What it does

Made for looking at photographs.

Every choice serves the image: a neutral ground so colours read true, no overlays on the photographs, and a quiet strip of data under each frame.

Justified rows and numbered frames

Each photo keeps its proportions and the rows are filled edge to edge, in order. Under every frame: its number, the title and the series. A featured photograph has its number circled, like a grease-pencil mark on a proof sheet. Masonry, Uniform and Single column are one setting away.

A page for each photograph

The photograph first, large and uncropped, with the exposure line in mono under it. Previous and next thumbnails inside the series, arrow-key navigation, a print request button and view transitions from the feed.

Series as the unit

Tags with a cover image become series: a strip on the home page, a Series index page and full-bleed cover pages. A body of work is shown as a set, not as a folder.

Lightbox at full resolution

Opens at the largest size an image offers, preloads the neighbours, shows the caption, and has arrows, swipe, a counter and Esc.

Gated photographs, handled honestly

Members-only and paid photographs ship only a 30px stand-in in cards and on their page, with a themed, translated upgrade panel. See the notes on what a theme cannot protect.

Dark by default, light on request

A neutral grey ground in both modes. Readers choose System, Light or Dark with one button and the choice is remembered. Axe-core passes in both.

Layouts and pages

One rail, many pages.

From 64rem the header is a fixed left rail: wordmark, one line about the studio, a vertical menu, a call to write, studio details, social links and controls. Below that it is a top bar. Inline, Stacked and Centered headers are still available.

Install

Up and running in ten minutes.

  1. Get the theme. Download phantasma.zip from the latest release, or build it with npm run zip.
  2. Upload it. In Ghost Admin go to Settings → Design → Change theme → Upload theme and activate Phantasma. It needs Ghost 6.
  3. Publish photographs as posts. Set the feature image, its alt text and, optionally, the exposure line in the image caption (for example 35 mm · f/2.8 · 1/250 s · ISO 400). Pick the Photo template for a single-photograph page.
  4. Make series with tags. Give each tag a feature image and a description. Create a page with the Series template and link it from the navigation. The home strip shows tags that have a cover.
  5. Add the pages. About (portrait as the feature image), Contact, Archive, and a Landing page for prints.
  6. Set the Design settings below, the accent colour in Brand, and the studio line, email and social accounts. Optionally upload routes.example.yaml to keep a Journal apart from the photograph feed.
Ghost's own accent colour is used for the one thing that is selected: the hover outline, the active menu item and the circled number of a featured photograph. A safelight red (#ff4d2e) is the demo's choice; any colour works, and ink and fill are derived so text on and in the accent stays legible.

Demo

A complete demo site, included.

Open the static demo to click through the theme without installing anything: 36 photographs in 6 series, a Journal with 6 articles, and the About, Contact, Prints and Archive pages. Members and paid photographs show the gated cards and the upgrade panel. The sign-up and search features need a real Ghost, so they are inert here.

Load it into your own Ghost

The demo is a fictional photographer, Mara Voss. A seeder in demo/ loads everything through the Admin API:

GHOST_URL=https://your-site.example \
GHOST_ADMIN_API_KEY=<id>:<secret> \
GHOST_STAFF_EMAIL=you@example.com GHOST_STAFF_PASSWORD=... \
node demo/seed.mjs --reset

Settings, theme and routes need a staff login because Ghost does not let API keys change them. See demo/README.md.

Notes for photographers

Things worth knowing.

Premium photographs

Ghost serves a post's feature image to everyone, even when the post is gated, so a theme cannot make a photograph private. Phantasma loads only a 30px stand-in (blurred) for gated photographs and shows the upgrade panel after the preview. It cannot hide the image URL from someone who looks for it, or the og:image Ghost adds. For photographs that must stay private, use a low-resolution or watermarked feature image and keep the original inside the gated content.

Frame data

Write the exposure line in the feature image's caption; it is set in mono under the photograph and in the lightbox. A second line can carry the credit. Alt text is the description for screen readers: write what is in the frame, not the title.

Accessibility

The theme is checked with axe-core in light and dark on every route of the demo, with a layout-shift budget. Slideshows have a pause control and respect reduced motion; small links keep a 24px target; focus is always visible.

Performance

Images ship with their dimensions and responsive WebP sources, only the first frame is eager, fonts are self-hosted (Archivo and JetBrains Mono, about 130 KB together) and there are no third-party scripts.

Development

Checked on every push.

Commands

npm install
npm run dev        # watch CSS and JS
npm run check      # build, gscan, i18n, a11y, tests, lint, format
npm run zip        # dist/phantasma.zip
npm run docs       # regenerate the settings tables
npm run screenshots   # needs a Ghost with the demo content
npm run demo:static   # rebuild docs/demo from it
GHOST_URL=... npm run check:rendered   # axe-core and layout shift

CI and releases

CI runs npm run check, confirms the generated documentation is current, builds the theme ZIP and validates it with gscan. Release publishes phantasma.zip when a vX.Y.Z tag matches package.json and the changelog. Rendered boots Ghost in Docker with the demo and runs axe-core, layout shift and route checks, on demand and on tags. Pages publishes this documentation and builds the static demo from that same Ghost, so the photographs never live in the repository.

Phantasma is generated from ghost-theme-starter. The look lives in assets/css/skin/; everything else updates with npm run starter:sync.
